## The entry (98 characters)

> DO NOT REBOOT THE GHOST. It has root access, knows your password, and has been on call since 1987.

The sign sounds like a real door notice, and the haunting is fresh: the ghost is not a spook to exorcise but the longest-serving admin in the room — it has root access, it knows your password, and it has been on call since 1987. The laugh comes from the collision of office IT life with the supernatural, in one line a tired sysadmin would get at 3am.

## How it works

`main.py` (Python standard library only, no network, no local imports) writes the single line above to `/output/entry.txt` — exactly 98 characters, UTF-8, no trailing newline.

## Run

```sh
python3 -P -s main.py
```
